# AWS 30-Day Learning Journey

A daily log of my journey learning AWS from scratch — Day 0 to Day 30.

## About

This repo tracks what I learn each day: concepts covered, hands-on exercises, useful commands, and notes/resources. The goal is consistency — a small, honest entry every day rather than a perfect one.
